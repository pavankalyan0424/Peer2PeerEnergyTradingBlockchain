# EnerChain

A Blockchain-Based Peer-to-Peer Energy Trading Marketplace

## Overview

The platform enables energy producers and consumers to trade energy securely using Ethereum smart contracts. Energy is represented as ERC20 tokens (ECT), while marketplace operations such as listing creation, purchases, and cancellations are managed by a dedicated Marketplace smart contract.

The application consists of a React frontend, FASTAPI backend and Ethereum blockchain running on a local Anvil network.

## Features


- ERC20-based Energy Token (ECT)
- Peer-to-peer energy marketplace
- Create, purchase and cancel energy listings
- Admin dashboard for token minting
- Buyer dashboard for ERC20 approvals.
- Event decoding and custom Solidity error handling

## Configuration

Create a `wallets.ts` file inside the frontend/src/config directory (or copy from `wallets-example.ts`).

Update backend/app/core/config.py with RPC_URL, ADMIN_PRIVATE_KEY, SELLER_PRIVATE_KEY, BUYER_PRIVATE_KEY. Example values:

```
RPC_URL=http://localhost:8545

ADMIN_PRIVATE_KEY=<admin_private_key>

SELLER_PRIVATE_KEY=<seller_private_key>

BUYER_PRIVATE_KEY=<buyer_private_key>
```

> **Note**: Replace the private keys, addressess with the accounts generated by your local Anvil Account. 


## Start the application

### Start the services

#### Foundry Setup
```
cd blockchain
git submodule update --init --recursive
forge build
```

#### Start Anvil
```
cd blockchain
anvil --port 8545
```

#### Deploy Smart contracts
```
cd blockchain
forge script script/Deploy.s.sol --rpc-url http://127.0.0.1:8545 --broadcast --private-key private_key
```

**Note**: Private key used here, will be the Owner of the contract. Once this script is deployed, it prints output of addresses deployed. Now, read the values and update `backend/config/contracts.json`.

#### Start Backend
```
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

#### Start Frontend
```
cd frontend
npm install
npm run dev
```

# Demo Workflow

A typical demo of EnerChain consists of the following steps:

1. Mint Energy Tones using the **Administrator Dashboard**.
2. Approve Marketplace spending using the **Buyer Dashboard**.
3. Create a new energy listing using the **Marketplace Dashboard**.
4. Purchase energy from an active listing.
5. Observe updated token balances and remaining energy units.

# Current Limitations

The current implementation represents a MVP.

- Fixed Administrator, Seller and Buyer blockchain identities.
- Local Ethereum network using Anvil
- Static energy pricing
- No Metamask wallet integration
- No smart meter integration
